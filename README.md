# 五十音练习 · Kana Trainer

日语五十音学习网页：手写板 + 罗马音随机测验。

## 功能

| 模式 | 说明 |
|---|---|
| 平假名练习 | 显示罗马音，在 Canvas 手写板写出**平假名**，点「写完了」自动显示平假名与片假名 |
| 片假名练习 | 显示罗马音，写出**片假名**，点「写完了」自动显示片假名与平假名 |
| 假名 ↔ 读音 | 随机显示平假名或读音（各 50%），输入答案后自动判定正误并显示答案，含正确率统计 |
| 五十音图 | 点击任意假名排除/恢复，支持全选、全不选、仅清音、反选 |

## 练习范围

底部开关可扩展范围，三个模式同步生效：

- 清音 46 个（默认）
- 浊音 · 半浊音 25 个
- 拗音 33 个
- 全开共 104 个

## 罗马音宽松判定

以下写法均判定为正确：

```
si = shi    tu = tsu    ti = chi    hu = fu
ja = zya    ju = zyu    jo = zyo    wo = o
```

## 快捷键

- 模式 1 / 2：`空格` 看答案，`Enter` 下一题
- 模式 3：`Enter` 提交判定

## 部署

单文件静态页面，零依赖、无外部请求，可直接双击打开或托管到任意静态服务。

- GitHub Pages：仓库 Settings → Pages → Source 选 `main` 分支 `/ (root)`
- Netlify / Vercel：拖拽整个目录即可

## 本地预览

```bash
python3 -m http.server 8000
```
